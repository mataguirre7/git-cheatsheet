Git Cheatsheets

Git guarda el historial de cambios de tu proyecto: podés ver qué cambió, volver atrás, probar cosas en paralelo y compartir el código en GitHub. Estas hojas están escritas para alguien que lo usa por primera vez: cada término se explica y la guía de Primeros pasos te lleva de cero a tu proyecto publicado.

Por dónde empezar

Si nunca usaste Git, seguí este orden. Si ya lo usás, buscá directo lo que necesitás.

  1. Conceptos: qué es un repositorio, un commit y las zonas por las que pasa un cambio (15 minutos de lectura).
  2. Primeros pasos: instalar, configurar, primer commit y subir el proyecto a GitHub. Hacelo con la terminal abierta.
  3. Uso diario: los comandos de todos los días, para tener a mano.
  4. Ramas y GitHub y remotos: trabajar en paralelo, pull requests y publicar en Netlify.
  5. Deshacer cambios y Problemas comunes: para cuando algo sale distinto de lo esperado.

Cómo leer los comandos de estas hojas

  • Los bloques oscuros son comandos para la terminal. Se ejecutan con Enter; si hay varias líneas, de a una. El botón de la derecha los copia.
  • <nombre>: reemplazalo por tu valor, sin los signos < >.
  • # texto: comentario, no se escribe.
  • Las palabras con guiones después del comando (-m, --oneline) son opciones que cambian lo que hace.
  • Los bloques grises con la etiqueta salida muestran lo que responde Git, para que compares.
  • Botón ☀/☾ arriba a la derecha: tema claro u oscuro. Ctrl+P → “Guardar como PDF” para imprimir.
